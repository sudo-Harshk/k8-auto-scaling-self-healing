# Archive: v1 handover documents (superseded)

These documents describe the **first version (v1)** of the project, as handed over in September 2026. They are kept for history only.

**They are superseded by the paper revision** (branch `paper-revision-eval`). Several v1 claims in these files were found to be incorrect or unsupported during the review and are withdrawn. Among them:
- the offline N = 10 comparison, which was a deterministic replay rather than live runs;
- the "56 sourced claims" evidence freeze;
- "17 decisions per minute";
- "all 28 proposals clamped or rejected".

For current, verified results see the top-level [README](../../../README.md) and [`Paper/REVIEW_EVIDENCE/`](../../../Paper/REVIEW_EVIDENCE/README.md).
